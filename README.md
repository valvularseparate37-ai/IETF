# IETF (ksriram25/IETF)

A curated collection of IETF-related materials, analyses, and data collected/produced by Kotikalapudi Sriram and collaborators. The repo contains technical notes, draft text (XML for xml2rfc), PDF presentations, and CSV datasets focused on routing security topics (RPKI/ROA, ASPA, AS path verification, SAV/BAR analyses, AS_SET analysis).

## What this is
A small archive of research notes, working-group drafts, dataset extracts, and presentation material related to Internet routing security (RPKI, route origin validation, ASPA, SAV, AS_SET analysis). Useful to researchers, network operators, and IETF sidrops/sidrops-adjacent contributors who want examples, datasets, or draft text for RPKI PrefixList, ASPA verification, and related analyses.

### Stack
- Language(s): plain text, XML (xml2rfc input), CSV, PDF
- Framework / runtime: none (documents and data rather than runnable code)
- Notable files / formats:
  - draft-ietf-sidrops-rpki-prefixlist-01.xml — xml2rfc-formatted Internet-Draft source
  - Multiple PDF slides and whitepapers (ASPA_*, BAR-SAV*, etc.)
  - CSV datasets: IPv4/IPv6 prefix lists related to AS0 ROAs and other summary data
  - Analysis text: Detailed-AS_SET-analysis.txt
